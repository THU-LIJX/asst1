# Problem 5 实验数据

实验时间：2026-10-15T12:05:51.330361+08:00 至 2026-10-15T12:06:16.865157+08:00。每个配置独立运行 10 次，N=20,000,000。每次保留原程序的内部三次最短耗时，统计跨启动中位数及四分位数；比值先按启动计算再取中位数。

源码只在临时副本中调整：default 完全沿用工作区输入和构建参数；no_autovec 仅在 C++ 增加 `-fno-vectorize -fno-slp-vectorize`；neon_x4 只调整 ISPC 逻辑宽度；tasks_* 只调整任务数。没有改变 SAXPY 算式或减少处理元素。所有任务数均整除 N，避免原程序非整除划分的问题。

每配置预热一次；种子 7 在每轮打乱配置，顺序执行。每个进程内部顺序仍为 C++、单核 ISPC、task ISPC。保留原程序基于 C++ 结果的两项逐元素校验，任何 Error 输出均视为失败。
